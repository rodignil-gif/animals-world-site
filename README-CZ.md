# Zvířata světa

Tento web představuje úžasný svět zvířat a fakty o nich.

## Popis

Web "Zvířata světa" obsahuje:
- Zajímavé fakty o zvířatech
- Sekce podle typů zvířat
- Rady pro ochranu přírody
- Lokalizaci v češtině

## Technologie

- HTML5
- CSS3 (Bootstrap)
- JavaScript

## Struktura souborů

- `index.html` - Hlavní stránka
- `style.css` - Styly
- `script.js` - Skripty

## Spuštění

Otevřete `index.html` v prohlížeči.
