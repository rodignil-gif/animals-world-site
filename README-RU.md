# Zvířata světa

Этот сайт знакомит с удивительным миром животных и фактами о них.

## Описание

Сайт "Zvířata světa" (Животные мира) содержит:
- Интересные факты о животных
- Разделы по типам животных
- Советы по защите природы
- Локализация на чешском языке

## Технологии

- HTML5
- CSS3 (Bootstrap)
- JavaScript

## Структура файлов

- `index.html` - Главная страница
- `style.css` - Стили
- `script.js` - Скрипты

## Запуск

Откройте `index.html` в браузере.
