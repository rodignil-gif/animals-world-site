# Animals World

This site introduces the amazing world of animals and facts about them.

## Description

The "Zvířata světa" (Animals World) site contains:
- Interesting facts about animals
- Sections by animal types
- Tips for nature protection
- Localization in Czech

## Technologies

- HTML5
- CSS3 (Bootstrap)
- JavaScript

## File Structure

- `index.html` - Main page
- `style.css` - Styles
- `script.js` - Scripts

## Running

Open `index.html` in a browser.
